Verify Provenance

Checks a signed provenance record exported from PC: that its signature matches the public key it carries, and that its content hash matches the artifact it describes. Runs entirely in this page — nothing is uploaded, and this file works the same opened from disk with no network at all.

Drop a .pcapp.json export here, or click to choose a file
What "verified" means here: the record's signature matches its own embedded public key, and the content hash matches the artifact bytes — proof this exact record was not altered after signing, and describes this exact artifact. It does not prove which person or organization holds the private key behind that public key — a browser app cannot manufacture that guarantee on its own. Treat a pass as chain-of-custody evidence, not a notarized identity claim.
